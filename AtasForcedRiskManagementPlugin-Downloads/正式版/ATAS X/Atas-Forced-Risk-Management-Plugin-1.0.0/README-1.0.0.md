# ATAS Forced Risk Manager 1.0.0

English: ATAS Forced Risk Manager monitors session loss and consecutive losing updates. When a configured risk limit is reached, it cancels working orders for the current account, attempts to close the current position, shows a fullscreen risk warning, and can request Windows shutdown.

中文：ATAS Forced Risk Manager 会监控本次会话亏损和连续亏损更新。当触发已设置的风险限制时，它会撤销当前账户挂单、尝试平掉当前持仓、显示全屏风险提示，并可请求 Windows 关机。

## Install / 安装

English: Copy `ATAS-Forced-Risk-Manager-1.0.0-ATAS-X.dll` to `%APPDATA%\ATAS\Strategies`, restart ATAS, and add `ATAS Forced Risk Manager` as a Chart Strategy.

中文：将 `ATAS-Forced-Risk-Manager-1.0.0-ATAS-X.dll` 复制到 `%APPDATA%\ATAS\Strategies`，重启 ATAS，然后将 `ATAS Forced Risk Manager` 添加为 Chart Strategy。

English: Test in simulation before using it with a live account.

中文：接入真实账户前请先在模拟环境测试。
