# Release Notes 1.0.0 / 版本说明 1.0.0

English:

- First stable TradingHub release for ATAS X.
- Added professional customer-facing risk-limit warning copy.
- Adds a quiet TradingHub latest-version check that only shows one small update line when a newer version exists.
- Keeps the risk response focused on the current account: cancel active orders, close the current position, and optionally request Windows shutdown.

中文：

- 首个面向 ATAS X 的 TradingHub 正式版本。
- 将风险限制提示整理为正式产品文案。
- 新增静默 TradingHub 最新版本检查；只有发现新版本时才显示一行小号提示。
- 风险响应保持聚焦当前账户：撤销活动挂单、平掉当前持仓，并可选择请求 Windows 关机。
