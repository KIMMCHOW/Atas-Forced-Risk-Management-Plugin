# Release Notes 1.0.1 / 版本说明 1.0.1

English:

- Improves Simplified Chinese fullscreen-warning and update-notice display compatibility.
- Settings and warning copy follow the ATAS interface language across the bundled localizations.
- Keeps the existing order-cancel, position-close, loss-limit, and optional shutdown behavior unchanged.

中文：

- 改善中文全屏风险警告和更新提示的显示兼容性。
- 设置与风险提示文案会跟随 ATAS 界面语言，并随 DLL 一起提供多语言资源。
- 既有撤单、平仓、亏损限制和可选关机逻辑保持不变。
